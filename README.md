# Termpad

Консольный текстовый редактор в духе `nano` для Windows: нумерация строк, подсветка синтаксиса, поиск и замена, отмена/повтор действий. Один исполняемый файл, без зависимостей.

## Возможности

- Подсветка синтаксиса: C#, Python, JavaScript/TypeScript, JSON (автоопределение по расширению, ручной выбор — `F2`)
- Номера строк и текущая позиция курсора
- Поиск, поиск далее, замена
- Отмена/повтор, вырезание/вставка строк
- Переход к строке, постраничная прокрутка
- Русский интерфейс и справка (`Ctrl+G`)
- Работа с UTF-8, сохранение через временный файл (без потери данных при сбое)

## Установка

Скачайте `TermpadSetup.exe` из раздела [Releases](../../releases) и запустите.

Установщик (для текущего пользователя, без прав администратора):

- распаковывает редактор в `%LOCALAPPDATA%\Programs\Termpad`
- добавляет `bin` в начало пользовательского `PATH`
- создаёт ярлык в меню «Пуск»
- регистрирует удаление в «Параметры → Приложения»

После установки откройте новый терминал:

```powershell
term
term file.txt
```

Короткий псевдоним — `nn`.

Параметры установщика:

| Параметр | Назначение |
| --- | --- |
| `--silent` | без вопросов и пауз |
| `--dir <путь>` | другая папка установки |
| `--no-path` | не менять `PATH` |
| `--no-shortcut` | не создавать ярлык |
| `--no-registry` | не регистрировать удаление |
| `--uninstall` | удалить редактор |

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+G` | справка |
| `Ctrl+O` | записать файл |
| `Ctrl+R` | открыть файл |
| `Ctrl+X` | выход |
| `Ctrl+W` | поиск |
| `Alt+W` | искать далее |
| `Ctrl+\` или `Ctrl+F` | замена |
| `Ctrl+K` | вырезать строку |
| `Ctrl+U` | вставить |
| `Ctrl+A` / `Ctrl+E` | начало / конец строки |
| `Ctrl+Y` / `Ctrl+V` | страница вверх / вниз |
| `Ctrl+D` / `Ctrl+H` | удалить символ / стереть символ |
| `Ctrl+L` | перейти к строке |
| `Ctrl+C` | позиция курсора |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отмена / повтор |
| `Alt+U` / `Alt+E` | отмена / повтор |
| `F2` | язык подсветки: авто/C#/Python/JS/JSON/нет |

Также работают стрелки, `Home`, `End`, `PgUp`, `PgDn`, `Enter`, `Tab`, `Backspace`, `Delete`.

## Сборка

Требования: Windows и .NET 8 SDK.

```powershell
.\build.ps1
```

Скрипт публикует self-contained приложение, упаковывает его в `installer\payload.zip` и собирает установщик в `dist\TermpadSetup.exe`.

Параметры:

```powershell
.\build.ps1 -Version 1.2.0 -Configuration Release -Runtime win-x64
```

Если `dotnet` не в `PATH`, скрипт ищет SDK в `%USERPROFILE%\.dotnet\dotnet.exe`.

## Релиз

```powershell
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions соберёт установщик и прикрепит его к релизу автоматически. Вручную:

```powershell
gh release create v1.0.0 .\dist\TermpadSetup.exe --generate-notes
```

## Удаление

«Параметры → Приложения → Termpad» или:

```powershell
TermpadSetup.exe --uninstall
```
